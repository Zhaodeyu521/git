## Git Commands

```bash
# 查看状态
git status

# 添加所有更改
git add .

# 提交
git commit -m "描述信息"

# 推送到 GitHub
git push

# 拉取远程更新
git pull

# 查看分支
git branch -a

# 创建并切换到新分支
git checkout -b 分支名
```
